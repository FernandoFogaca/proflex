# ProFlex - Refactoring Plan

Date: 2026-11-12

## Objective
Simplify navigation, reduce duplicated features and improve usability without losing existing functionality.

## Planned improvements
- Agenda: prioritize patient search and quick registration.
- Scheduling: separate administrative tasks from clinical assessments.
- Patient care: unify initial assessments and follow-up consultations.
- Medical records: organize clinical history, consultations and documents.
- Appointments: simplify access to personal and administrative commitments.
- Data: review Firestore persistence and prevent duplicate records.
- Security: implement role-based permissions and review data protection.

## Next steps
Start by simplifying the scheduling workflow, followed by clinical consultation integration and security validation.

Status: Planning completed. Implementation pending.
